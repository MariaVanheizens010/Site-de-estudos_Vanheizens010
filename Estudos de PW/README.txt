estrutura de estudos — MODELO DE SITE


ARQUIVOS:
- index.html: página inicial com biblioteca e cards.
- 6 páginas HTML: uma página individual para cada história.
- style.css: todo o estilo visual.
- logo.png: logo usado no cabeçalho.

COMO FUNCIONA:
1. Abra index.html no VS Code.
2. Use o Live Server.
3. Cada card tem um link para uma página de história.
4. Cada página possui uma lista lateral de capítulos.
5. Os capítulos ficam na mesma página e usam IDs (#cap-1 etc.).

PARA ADICIONAR UMA HISTÓRIA:
- Duplique uma página de história.
- Troque título, resumo, tags e textos.
- Adicione um novo card no index.html apontando para a nova página.

OBSERVAÇÃO:
este site foi desenvolvido parcialmente por IA, para os estudos da aluna  e compreensão de novas habilidades.
